# Sample User Story

**ID:** `sample-author-updated-sample-assets`  
**Type:** `spec_builder.user_story`  
**Parent epic:** `sample-spec-builder-refresh-epic`

## Story
As a Spec Builder maintainer, I want packaged samples to match the current schemas so that seeded artifacts are trustworthy examples.

## Description
This sample story shows how a user story can express the maintainer need behind the packaged sample refresh. It also demonstrates the relationship between a story, its parent epic, and its linked validation test case.

## Acceptance Criteria
- A maintainer can open any packaged sample and understand the current artifact structure.
- The sample markdown files read like representative authored documents.
- The sample JSON hierarchy uses consistent ids and current type names.

- `sample-validate-packaged-samples`
