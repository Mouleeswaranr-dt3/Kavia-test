# Sample Epic

**ID:** `sample-spec-builder-refresh-epic`  
**Type:** `spec_builder.epic`  
**Parent roadmap item:** `sample-spec-builder-refresh`

## Summary
This sample epic groups the work required to restore realistic packaged Spec Builder samples. It exists to show how an epic can summarize scope, priority, linked stories, and acceptance criteria in a human-readable companion example.

## Scope
- Refresh outdated or placeholder sample JSON assets.
- Refresh placeholder sample Markdown assets.
- Keep roadmap, story, and test case references internally consistent.

## Linked Stories
- `sample-author-updated-sample-assets` — maintain packaged examples that match the current schema expectations.

## Acceptance Criteria
- Every registered artifact type has a representative sample.
- The sample content demonstrates realistic values rather than placeholders.
- Downstream readers can understand the intended artifact structure from the examples alone.
