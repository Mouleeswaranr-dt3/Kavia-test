# Specifications

## Overview

This section contains forward-looking, implementable specifications for planned product and engineering work.

## Specification Collections

The [Feature Specs](FeatureSpecs/index.md) collection contains product requirements and acceptance criteria for user-visible capabilities.

The [Detailed Designs](DetailedDesigns/index.md) collection contains implementation-oriented interaction and system designs for scoped work.

The [Other Specifications](Other/index.md) collection contains supporting forward-looking analysis documents that inform future architecture and delivery decisions without changing approved product requirements.
